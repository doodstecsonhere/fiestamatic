# Fiestamatic v1.0.0 — draft release notes

> Draft only. Do not create the tag or publish a GitHub Release until the owner
> explicitly approves the reviewed implementation, production deployment, tag,
> and release.

Fiestamatic v1.0.0 is the first stable, Replit-independent release of the
mobile-first Dumaguete City fiesta guide.

## Highlights

- Browse and search barangay fiestas, dates, countdowns, local history, patron
  saints, and traditions.
- Explore an interactive Dumaguete map with accessible barangay markers and
  fiesta-detail dialogs.
- Use the shared Bayanihan board for public community posts with ownership,
  reporting, moderation, rate limiting, validation, and deletion safeguards.
- Install the application and revisit its cached home, fiesta information,
  navigation, community fallback, and bundled offline map without a network
  connection.

## Map and attribution

The map replaces the affected CARTO Voyager endpoint with OpenStreetMap
Foundation Standard tiles for normal online interaction. It displays visible
`© OpenStreetMap contributors` attribution and requires no secret key,
account, trial, card, or paid plan.

OSMF does not permit offline prefetching from its Standard tile service.
Fiestamatic therefore uses its own bundled Dumaguete schematic offline or when
tiles fail. The fallback retains all barangay markers and fiesta information
without making a network request.

The full provider policy and zero-dollar decision are recorded in
`docs/maps/zero-dollar-map.md`.

## Known limitations

- OSMF Standard tiles are best effort, carry no service-level guarantee, and
  may be blocked if usage violates policy or becomes too heavy.
- Arbitrary uncached third-party map areas are not available offline. The
  bundled schematic provides intentional barangay context instead.
- The shared Bayanihan board needs network access to publish or synchronize.
  Its cached view remains available when the server cannot be reached.
- Display names on the community board are not verified identities.
- The production JavaScript bundle still has the existing large-chunk build
  warning; this does not block the map fix but remains a future performance
  improvement.

## Rollback

1. Revert the implementation through a reviewed revert PR; never reset or
   force-push `main`.
2. In Cloudflare Pages, select deployment
   `96085331-3363-451b-947c-3a280e4d9689` (source `e2dde66`) as the
   application rollback.
3. Keep D1 binding `DB` and `fiestamatic-bayanihan` unchanged.
4. Do not use D1 Time Travel to roll back application code.
5. Keep the independent Replit deployment unchanged as the emergency fallback.

Reverting application code does not restore or alter database records,
configuration, storage, secrets, domains, or external-service state.
